# Task 1 – Exploring and Visualizing a Simple Dataset

##  Task Objective

The objective of this task is to explore the Iris dataset through data inspection and visualization. This helps in understanding data structure, distribution, and relationships between features — a fundamental step before applying any machine learning models.

---

##  Dataset Used

- **Name**: Iris Dataset  
- **Source**: Built-in dataset from the `seaborn` library (`sns.load_dataset("iris")`)  
- **Features**:
  - `sepal_length`
  - `sepal_width`
  - `petal_length`
  - `petal_width`
  - `species` (target)

---

##  Models Applied

No machine learning models were used in this task.

This task focused on:
- Loading and inspecting data with **pandas**
- Visualizing relationships and distributions with **matplotlib** and **seaborn**

---

##  Key Results and Findings

- **Scatter Plot**: Shows strong correlation between petal length and sepal length, varying across species.
- **Histograms**: Reveal distinct value distributions, with petal features clearly separating species.
- **Box Plots**: Highlight feature spread and outliers. Petal-based features show clear differences among species.
